## 📝 Quick Tasks

### Add Product Images:
1. Go to Admin → Products
2. Click Edit on any product
3. Click "Upload Image"
4. Select image file
5. Save

### Update Contact Info:
1. Go to Admin → Settings
2. Update email, phone, address
3. Save changes

### Change Admin Password:
1. Login to admin
2. Go to Profile/Settings
3. Change password
4. Save
